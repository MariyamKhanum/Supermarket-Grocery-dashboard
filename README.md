# Supermarket-Grocery-dashboard
This is an interactive Supermarket Grocery Sales Dashboard built using Power BI to analyze sales, profit, and state-wise performance. It highlights high-sales, low-profit locations and helps identify trends, compare regional performance, and uncover actionable business insights through clear, interactive visualizations for better decision-making.
